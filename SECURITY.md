# Security Policy

## Reporting a vulnerability

If you find a security issue in any agent-accessibility project, please report it privately.

**Email:** s.hashwanth531@gmail.com

**Do not** open a public GitHub issue for security vulnerabilities.

I'll acknowledge your report within 48 hours and work with you on a fix before any public disclosure.

## Supported versions

Only the latest release on the `main` branch is actively supported with security patches.
