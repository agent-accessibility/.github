# Contributing to Agent Accessibility

Thanks for wanting to contribute. Here's the short version.

## Getting started

Each project has its own setup instructions in its README. For KMCP specifically, see [CONTRIBUTING.md](https://github.com/agent-accessibility/KMCP/blob/main/CONTRIBUTING.md) in the repo.

## How to contribute

1. Check existing issues before opening a new one
2. For bugs, include steps to reproduce
3. For features, open an issue first so we can discuss the approach
4. Fork, branch, PR. Keep PRs focused on one thing.

## Code style

- Python: PEP 8 + type annotations on public functions
- Frontend: Next.js App Router conventions
- Commit messages: short, lowercase, describe the "why" not the "what"

## License

By contributing, you agree that your contributions will be licensed under the same license as the project you're contributing to (AGPL-3.0 for backend code, MIT for frontend code).
